# The skippable-path table for the change-set scope gates (audit S5): one
# place to add a path class so all four gates see it, instead of the set
# living as a case in one gate, a case in another and two regexes in the rest.
#
#   <target>  <run|skip>  <ERE matched against each changed path>
#
# A gate consults only its target's rows, in file order: the first row whose
# pattern matches a path decides that path — skip means the path cannot reach
# the gate, run means it can (the parity and build-script edges). A path
# matching no row reaches the gate: the failure mode must be a wasted minute,
# never a regression that merges green, so a suite skips only when EVERY
# changed path matches a skip row.
#
# Targets: unit/frontend, unit/backend and unit/server (unit-test-scope.sh), lighthouse
# (lighthouse-scope.sh), worker-smoke (worker-smoke-scope.sh), e2e-smoke
# (e2e-smoke-scope.sh). The policy rationale lives in each gate's header; the
# offline guard suites (./scripts/test.sh unit-test-scope, lighthouse-scope,
# smoke-scope, e2e-smoke-scope) pin this table through the gates. reaches.sh
# keeps its own policy: it triggers on positive generator inputs, not on a
# skip set.
# server/ is the v2 package (Phase 2, #763): no v1 suite, bundle, audit or
# generator reads it, so every v1 target below has a `skip ^server/` row. The
# v2 suite (unit/server) is fed by server/, the shared test plumbing under
# scripts/, root manifests and anything unknown; it has no `run` row because a
# path matching no row already runs (fail safe).

# unit-test-scope — the frontend suite tests frontend/src (and
# frontend-dom); the backend suite tests backend/src with contract/.
unit/frontend run   ^backend/src/plugins/
unit/frontend skip  ^docs/
unit/frontend skip  ^\.agents/
unit/frontend skip  ^automation/
unit/frontend skip  \.md$
unit/frontend skip  ^backend/
unit/frontend skip  ^contract/
unit/frontend skip  ^tools/
unit/frontend skip  ^server/

unit/backend skip   ^docs/
unit/backend skip   ^\.agents/
unit/backend skip   ^automation/
unit/backend skip   \.md$
unit/backend skip   ^frontend/
unit/backend skip   ^tools/
unit/backend skip   ^server/

# unit-test-scope — the v2 suite runs `bun test` from server/ (wired in R2);
# it shares the test plumbing under scripts/ with v1, so scripts/, root
# manifests and unknown paths run it.

unit/server skip    ^backend/
unit/server skip    ^frontend/
